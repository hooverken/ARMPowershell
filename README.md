# ARMPowershell

Miscellaneous PowerShell scripts and templates I've created for use with Azure Resource Manager (ARM), Azure Virtual Desktop, and related Windows administration tasks.

The table below lists every top-level tool folder, including local-only and empty folders, plus the standalone script in the repository root. Where available, see the folder's README for setup and usage details; otherwise, review the script's comments and parameters before running it.

## Contents

| Folder or File Name | Description |
| --- | --- |
| [AlertOnFileShareConsumedCapacityPct](AlertOnFileShareConsumedCapacityPct/) | Contains PowerShell and Bicep examples for creating an Azure Files capacity alert based on a percentage of provisioned share capacity. Useful for notifying an action group before a premium file share fills up. |
| [Configure-AzFilesShareForFSLogixProfileContainers](Configure-AzFilesShareForFSLogixProfileContainers/) | Sets up an Azure Files share and configures permissions for FSLogix profile containers. Use it when preparing shared profile storage for Azure Virtual Desktop users. |
| [Configure-AzFilesShareForMSIXAppAttach](Configure-AzFilesShareForMSIXAppAttach/) | Applies Azure role assignments and NTFS permissions to an Azure Files share for MSIX app attach. Useful when preparing application package storage for Azure Virtual Desktop session hosts. |
| [Configure-AzStorageAccountForAADHybridAuthn](Configure-AzStorageAccountForAADHybridAuthn/) | **Empty placeholder:** no scripts or documentation are currently present. This folder does not yet contain a usable tool. |
| [Configure-AzStorageAccountForADDSAuthn](Configure-AzStorageAccountForADDSAuthn/) | Configures an Azure storage account for Active Directory Domain Services (AD DS) authentication. Use it to enable identity-based access to Azure Files with an existing AD DS domain. |
| [Configure-FSLogix](Configure-FSLogix/) | Creates Windows registry settings to enable FSLogix profile containers on the target machine. Useful for manual configuration or testing when settings are not being deployed through a management tool such as Intune. |
| [Convert-AzVmToNVMe](Convert-AzVmToNVMe/) | Prepares a Windows Azure VM for NVMe storage and rebuilds its compute configuration at a specified VM size using its existing disks and network interfaces. Intended for migrations to NVMe-based sizes; review carefully and plan for downtime. |
| [Enable-AzStorageAccountForAzureAdAuthentication](Enable-AzStorageAccountForAzureAdAuthentication/) | Configures an Azure storage account for Azure AD (now Microsoft Entra ID) Kerberos authentication. Useful when enabling Azure Files access for hybrid identities through Microsoft Entra Kerberos. |
| [Enable-DiagnosticsForResource](Enable-DiagnosticsForResource/) | Configures supported diagnostic logs and metrics to be sent to a Log Analytics workspace, with flow-log setup for network security groups or virtual networks. The current script is limited to those network resource types and includes environment-specific settings that need review before use. |
| [Exterminate-AzureVM](Exterminate-AzureVM/) | Deletes an Azure VM's compute resource, OS disk, data disks, and network interfaces. **Destructive:** use only when you intend to remove the VM and its associated storage and networking components. |
| [Get-AvdHostPoolBilledCharges](Get-AvdHostPoolBilledCharges/) | Returns billed compute and disk charges for an Azure Virtual Desktop host pool over a specified period, defaulting to the previous 30 days. **Superseded** by [host-pool cost grouping in Azure Cost Management](https://techcommunity.microsoft.com/t5/azure-virtual-desktop-blog/group-costs-by-host-pool-with-cost-management-now-in-public/ba-p/3638285). |
| [Get-AzLogicalToPhysicalAzMappings](Get-AzLogicalToPhysicalAzMappings/) | Shows how a subscription's logical availability zone numbers map to physical zones in a region. Useful when placement must match a specific physical zone rather than just a subscription-local zone number. |
| [Get-AzureMaintenanceEvents](Get-AzureMaintenanceEvents/) | Polls Azure VM Scheduled Events and writes maintenance notifications to the local Windows Application event log. Includes setup and test modes for a scheduled-task-based workflow, with events intended for collection into Log Analytics. |
| [Get-AzVmRestrictions](Get-AzVmRestrictions/) | Reports VM SKU restrictions at the region and availability zone levels for the current subscription, supporting multiple SKUs and regions. Useful for identifying subscription-specific deployment restrictions; it does not guarantee live capacity. |
| [Get-ExpressRouteLocationSpeedOfferings](Get-ExpressRouteLocationSpeedOfferings/) | Lists ExpressRoute Direct port locations and their available 10 Gbps and 100 Gbps offerings, with location-name and Metro-only filters. Useful for connectivity planning; choose a peering location near your on-premises site rather than simply near an Azure region. |
| [Get-SubscriptionPairAZMappings](Get-SubscriptionPairAZMappings/) | Compares availability zone mappings between the current subscription and a target subscription. Use it to identify logical zone numbers that correspond to the same physical zone across subscriptions. |
| [Get-VmSkusWithHostBasedEncryptionSupport](Get-VmSkusWithHostBasedEncryptionSupport/) | Lists VM sizes in a specified region that support encryption at host. An optional inverse filter lists sizes that do not support it, helping narrow VM choices for security requirements. |
| [Request-AzComputeQuotaChange](Request-AzComputeQuotaChange/) | Contains scripts to submit a regional VM-family core quota change request and check quota request status through the Azure API. Useful for requesting additional compute quota and tracking approval or provisioning progress from PowerShell. |
| [ScheduledAzCopyToBlob](ScheduledAzCopyToBlob/) | Demonstrates unattended copying of files older than a specified age to Azure Blob Storage using AzCopy and certificate-based service principal authentication. Includes a service principal creation example; **demo code only, not production-ready**. |
| [Rotate-LetsEncryptCertificate.ps1](Rotate-LetsEncryptCertificate.ps1) | Automates a Let's Encrypt certificate request or renewal using an HTTP challenge and stores the resulting certificate in Azure Key Vault. Review the required Blob Storage and Application Gateway challenge-routing configuration, along with environment-specific values, before use. |

Many scripts include explanatory comments and support the `-Verbose` parameter for a detailed view of their progress. Requirements and readiness vary by tool; check prerequisites, Azure subscription context, permissions, and any hard-coded settings before running a script, especially one that changes or deletes resources.
